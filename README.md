# readMeasy (read-em-easy)

A Chrome extension that translates selected text in place, so you can read Bengali or Hindi posts in English without leaving the page.

## Features

- Translate Bengali or Hindi to English (or auto-detect the language)
- The translation replaces the original text right where it is
- Works on dynamic sites like Facebook and Instagram
- Show selected Bengali text in an easier-to-read font (Bornomala)
- Restore the original text with one click

## How to use

1. Select the text you want to translate.
2. Click the ReadMEasy icon and press **Translate**.
3. Or press **Easier Bengali font** to keep the Bengali text but display it in Bornomala.
4. Press **Restore original** to bring the original text back.
